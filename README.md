Welcome to my **LeetCode Solutions** repository!

## Repository Structure

Each problem is organized in its own directory using the following format:

```
leetcode-solutions/
│
├── 0001-two-sum/
│   ├── Solution.java
│   └── README.md
│
├── 0002-add-two-numbers/
│   ├── Solution.java
│   └── README.md
│
├── 0019-remove-nth-node-from-end-of-list/
│   ├── Solution.java
│   └── README.md
│
└── ...
```

Each folder contains:

- **Solution.java** – Java implementation of the solution.
- **README.md** – Explanation of the approach, algorithm, and complexity analysis.
